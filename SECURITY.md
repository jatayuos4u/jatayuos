# Security reporting

Report suspected vulnerabilities privately to **jatayuos4u@gmail.com**. Please do not put exploit details, credentials or personal data in public issues. Include the JatayuOS version, ISO source commit/checksum where available, affected component, impact and reproducible steps. Redact private information from logs.

There is no guaranteed response time or published long-term support commitment. Consult Debian security advisories for Debian packages and report upstream-specific vulnerabilities through the relevant project's security channel. Original Jatayu application updates do not currently have a separately configured signed APT repository.

Repository hardening does not imply that a previously built ISO has changed. See [the build security audit](docs/SECURITY-AUDIT-2026-10-09.md) for review scope, checks and remaining risks.
