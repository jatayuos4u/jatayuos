# Third party notices and source index

This is a project-level credit index, not the complete package-by-package legal
notice bundle for Build 35. Publish the exact third-party-notices/ output from
that release beside the ISO, source archives and package-manifest.tsv.

| Foundation or component | Role | Authoritative release evidence |
| --- | --- | --- |
| Debian and Linux contributors | Base packages, kernel and system tools | Exact source/version manifest and installed copyright files |
| KDE contributors | Plasma desktop and applications | Per-package notices/source from the manifest |
| Mozilla contributors | Firefox ESR | Package notices/source plus the applicable branded distribution route |
| The Document Foundation and LibreOffice contributors | Office applications | Per-package notices/source |
| Qt, PySide and PyQt contributors | Desktop application frameworks | Exact module/package notices and terms |
| Calamares contributors | Installer | Debian source 3.3.14-1 plus Jatayu patch/build material |
| Fcitx contributors | Input methods | Debian source 5.1.12-2 plus Jatayu patch/build material |
| Waydroid contributors | Optional Android integration | Package source/notices; downloaded Android images are separate |
| Other package, font, driver and firmware contributors | Supporting components | Exact manifest and per-component notices |

Existing GPL license texts and application notices remain intact. No blanket
license or rights grant overrides these components' individual terms.
The downstream source package set must match the shipped ISO, not merely this
repository's direct package list. Refer to docs/legal/SOURCE-PUBLICATION.md.
