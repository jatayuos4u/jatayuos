JatayuOS 0.1

Release Candidate · Made in India

Udaan Aapki. Shakti Bharat Ki.

Created and maintained by Anup Yadav. An independent desktop project built on Debian 13, the Linux kernel and KDE Plasma, with Mozilla Firefox ESR and LibreOffice.

Why JatayuOS?

The name draws on the courage, service and protection associated with Jatayu in the Ramayana. It connects the project's identity with Indian culture. Made in India describes the project's origin; the operating system also depends on global open-source contributions.

Applications made for your desktop

Aarambh: welcome, help and everyday shortcuts. Jatayu Editing Tools: image and PDF utilities. Jatayu Wallpaper Changer 1.2.1: an offline gallery, favourites and rotation. Kavach: system dashboard. Sarkar Setu: public-service links. Utsav: the supplied local web app. The shared suite also includes personal-folder backup, diagnostics, language settings and Android readiness entry points.

Everyday software: Dolphin, Konsole, Kate, Ark, Gwenview, Okular, Spectacle, Discover, System Settings, LibreOffice, Firefox ESR, Partition Manager, GParted, Fcitx5 and Waydroid. Android needs separate image setup and compatible hardware.
