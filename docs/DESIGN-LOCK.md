# JatayuOS approved desktop direction

Approved by the project owner on 2026-09-28. This development build targets the supplied gold shield logo, cinematic eagle landscape wallpaper at 1920 x 1080, dark full-width bottom panel, and application menu with categories and Jatayu Tools. The live desktop provides Install JatayuOS, JatayuOS FAQ, and User Manual. Jatayu Welcome replaces the Plasma Welcome autostart. The Debian installer duplicate is hidden; the Jatayu installer remains accessible. Plymouth pulses the supplied shield.

The design sample is a visual target. Plasma Kickoff supplies the menu functionality; its exact rendering depends on the installed Plasma version and display scale. Verify the finished ISO in a VM before considering a release. The owner supplied the shield and wallpaper reference; the wallpaper is an approved derivative for this development build.
