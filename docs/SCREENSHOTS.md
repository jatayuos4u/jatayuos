# JatayuOS screenshot provenance

## Current documentation captures

The owner supplied ten VM screenshots following acceptance of Build #35.
They were used in the separately delivered illustrated User Manual, with
selected captures also used in the Installation Guide. They show genuine
captured interfaces, not manufactured UI mockups.

| Original filename | Dimensions | Subject |
| --- | --- | --- |
| boot-menu.png | 640 × 480 | BIOS-style live boot menu |
| plymouth-screen.png | 1280 × 800 | Boot logo |
| Welcome-screen.png | 1280 × 800 | Live welcome, not the installed Aarambh view |
| desktop.png | 1280 × 800 | Live desktop and installer shortcuts |
| Menu(1).png | 1280 × 800 | Jatayu Tools menu category |
| jatayu-tools.png | 1280 × 800 | Creative Studio workspace |
| walpaper-changer.png | 1280 × 800 | Wallpaper library and controls |
| kavach-app.png | 1280 × 800 | Guidance and system-action shortcuts |
| sarkar-setu.png | 1280 × 800 | External service directory |
| utsav-app.png | 1280 × 800 | Festival/calendar interface |

Native PNGs were embedded losslessly at readable page sizes. The boot menu
was displayed smaller to match its lower resolution. Controls, labels and
status values were not invented or retouched.

Exact image hashes are recorded in
[candidate metadata](releases/1.0-udaan-candidate.json). Raw captures have not
been copied into the repository by this release-preparation commit; they remain
owner-supplied documentation inputs and are embedded in the delivered manual.
See [documentation inventory](DOCUMENTATION.md) for the PDF hashes.

Screenshot clocks, dates, sample paths and app status labels belong to the
captured VM session. They do not independently certify security, portal URLs,
calendar accuracy, installed-system behavior or hardware compatibility.
The boot capture does not establish a complete BIOS installation test.
