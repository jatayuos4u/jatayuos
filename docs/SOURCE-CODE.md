## What this does and does not provide

This GitHub revision gives public access to the JatayuOS project's tracked code, scripts, configurations and historical files as they existed at the Build #38 source commit. Original JatayuOS code is licensed under GPL-3.0-or-later where applicable. Other files and bundled software retain their own licensing.

**The project GitHub repository is not yet a complete corresponding-source distribution for all third-party binary packages bundled in Build #38.** The Build #38 manifest lists 1,507 binary packages and 829 source/version pairs. A separate third-party notice ZIP has filename coverage for those packages; full source archives, modifications, and distribution-license requirements require additional verification and delivery.

The exact source-collection procedure and the unresolved requirements are listed in [Build #38 source-publication plan](legal/BUILD38-SOURCE-PUBLICATION.md). Never claim a source bundle, public ISO URL or complete legal clearance merely because this source-code page is public.
